# KOVENA — The Table of Four

> *Tempat orang saling terhubung secara nyata.*

Landing page dan alur onboarding interaktif untuk **KOVENA**, sebuah ruang bertatap muka beranggotakan empat orang di satu meja untuk mengembalikan hangatnya koneksi manusia tanpa distraksi layar.

## 🌿 Desain & Filosofi
- **Estetika:** Warm Minimalism, Quiet Luxury, Editorial, Calm Sunset Atmosphere.
- **Warna Utama:** Warm Alabaster (`#F7F5F0`), Muted Warm Stone (`#EFECE6`), Sunset Terracotta (`#B85D3B`), Deep Field Olive (`#3A4A3E`), Espresso Charcoal (`#1E1E1C`).
- **Tipografi:** Instrument Serif, Cormorant Garamond, Plus Jakarta Sans.

## 📁 Struktur Berkas
- `index.html` — Struktur semantik HTML5, konfigurasi Tailwind CSS, dan komponen antarmuka.
- `styles.css` — Efek tekstur kertas halus (*paper grain*), animasi *scroll reveal*, dan transisi tumpukan 3D.
- `app.js` — Logika interaktif SVG *The Table of Four*, pembalik kartu pertanyaan, dan *onboarding modal* (Typeform-style).
- `package.json` — Konfigurasi dev server lokal (`serve`).

## 🚀 Menjalankan Secara Lokal
Buka berkas `index.html` langsung di browser, atau gunakan:
```bash
npx serve . -l 3000
```
